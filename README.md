# one-line-pitch

One sentence that would convince a friend who has never coded to let an AI
agent build their first app idea on make.fun, written to `/output/entry.txt`
by `main.ts` (Node 22). Built for the make.fun bounty
[A Day of One-Line Pitches](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3).

## Run

```sh
node main.ts
```

It writes the sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`).
